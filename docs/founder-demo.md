# Five-minute founder demo

0:00–0:30 — Problem: staffing teams coordinate manually, and coverage changes are difficult to track. ShiftPatch puts open shifts and their assignments in a shared workspace.

0:30–1:30 — Sign in as Sunrise. Publish an overnight shift. Sign in as Maria and claim it. Show the agency sees coverage. Explain that two nurses cannot take the same opening.

1:30–2:15 — Sign in as James and demonstrate the expired-licence rejection. Show document upload and administrator review. Explain that this is a synthetic-data trial, and uploading a document does not automatically prove its validity.

2:15–3:00 — Cancel an assignment or mark no-show. Show the shift reopens and its history stays available. Record actual work hours, submit and approve them.

3:00–4:00 — Show administrator coverage, cancellations, approved hours and audit history. Export a report and a private document package; explain any missing documents in the manifest.

4:00–4:30 — Describe notification status honestly: queued, sent or configuration pending. Show analytics only if the service has been configured and events actually verified.

4:30–5:00 — Explain boundaries: dashboard refreshes periodically, registry research is not automated, and real medical-document deployment requires a separate operational review. State any remaining incomplete integrations explicitly. Share deployed URL and repo with verified CI.

Before recording: use a dedicated demo scenario; do not silently reset evaluation data. Avoid exposing API keys or infrastructure credentials.
